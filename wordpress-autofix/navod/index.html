Jak vygenerovat Application Password

Heslo aplikace z WordPressu, ne běžné přihlašovací heslo.

  1. Přihlaste se do WordPress adminu. Pro SEO opravy stačí Editor; pro rychlostní vylepšení (pluginy, Smush) potřebujeme Administrátora.
  2. Otevřete Uživatelé → Profil (Users → Profile).
  3. Najděte sekci Application Passwords (Hesla aplikací).
  4. Název aplikace zadejte např. GoFixWeb.
  5. Klikněte na Přidat nové heslo aplikace. WordPress jednorázově zobrazí heslo tvaru xxxx xxxx xxxx xxxx xxxx xxxx.
  6. Heslo zkopírujte a vložte do onboarding formuláře. Do databáze GoFixWeb se ukládá jen šifrovaně.

Vyžaduje WordPress 5.6+, HTTPS na produkci a zapnuté REST API (/wp-json/).
